# Rule: Ignore the Walkthroughs Folder in Codebase Analysis

The `walkthroughs/` subfolder of the memory bank (for example `memory-bank/walkthroughs/`, or the equivalent in a variant-named memory bank folder) is excluded from whole-codebase analysis.

## Skip it when
- Searching, summarizing, auditing, reviewing, or onboarding across the whole workspace.

## Read it only when
- Adding or updating a walkthrough.
- The user asks about walkthrough contents or points to a specific walkthrough.

## Scope
This applies only to `walkthroughs/`. Other memory bank content is unaffected.
